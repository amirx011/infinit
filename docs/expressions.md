# نحو عبارات

## ۱. کلیات

- ورودی یک معادله یا یک عبارت است.
- فاصله‌ها آزادند.
- نویسه‌های یونیکد رایج نرمال می‌شوند: `−` → `-`، `×` → `*`، `÷` → `/`، `π` → `pi`.
- نام متغیرها به حروف لاتین محدود نیست، اما برای سازگاری `x`، `y`، `c` توصیه می‌شوند.

---

## ۲. معادله و مشتق

| نوشتار | معنی |
|---|---|
| `y' = y` | مشتق اول |
| `y'' + y = 0` | مشتق دوم |
| `y''' - y = 0` | مشتق سوم |
| `dy/dx = y` | مشتق اول |
| `y = x*y' + (y')^2` | کلرو |
| `(2x+y) + (x+2y)*y' = 0` | شکل صریح |
| `(x+y)dx + (x+2y)dy = 0` | شکل دیفرانسیلی |

سمت راست اختیاری است؛ `y' = 0` معادل `y'` بدون `= 0` است.

> علامت پریم فقط بعد از یک نام متغیر معتبر است. `y'` و `y''` به `Deriv(y, x, n)` تبدیل می‌شوند.

---

## ۳. عملگرها

| عملگر | نمونه | توضیح |
|---|---|---|
| `+` `-` | `x - 2` | جمع و تفریق |
| `*` | `2*x` | ضرب صریح |
| ضرب ضمنی | `2x`, `3(x+1)`, `(x+1)(x-1)`, `2xy`, `2XY` | بین عدد/پرانتز و متغیر/پرانتز؛ دنبالهٔ حروف کوتاه هم به ضرب تبدیل می‌شود (`2xy` → `2*x*y`، `2XY` → `2*X*Y`). نام توابع (`exp`, `atan`, ...)، ثابت‌ها (`pi`, `e`) و نمادهای دیفرانسیل (`dx`, `dy`) شکسته نمی‌شوند. |
| `/` | `x/y` | تقسیم |
| `^` یا `**` | `x^2`, `x**(1/2)` | توان |
| `()` `[]` `{}` | `(x+1)` | پرانتزگذاری |
| `|...|` | `|x|` | قدر مطلق |

توان راست‌شرکت است: `2^3^2 = 2^(3^2) = 512`.

---

## ۴. اعداد

- صحیح: `42`, `-7`
- اعشاری: `0.25` → کسر دقیق `1/4`
- کسری: `1/3` (به‌صورت تقسیم دو عدد صحیح)
- اعداد بزرگ که از `int64` بیرون بزنند، خطای سرریز می‌دهند.

هیچ تبدیل خودکار به `double` انجام نمی‌شود.

---

## ۵. توابع

| گروه | توابع |
|---|---|
| مثلثاتی | `sin`, `cos`, `tan`, `cot`, `sec`, `csc` |
| وارون مثلثاتی | `asin`, `acos`, `atan` |
| هذلولوی | `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh` |
| نمایی/لگاریتمی | `exp`, `ln`, `log` (هر دو لگاریتم طبیعی) |
| دیگر | `sqrt`, `abs` |

نمونه‌ها:

```
sin(x)
exp(-x)
ln(abs(y))
sqrt(x^2 + 1)
```

`e` و `pi` به‌عنوان ثابت‌های نمادین شناخته می‌شوند.

---

## ۶. قراردادهای جواب

| حالت | نمایش |
|---|---|
| صریح | `y = f(x)` |
| ضمنی | `u(x,y) = C` |
| پارامتری | `x(p) = ...`، `y(p) = ...` |
| منفرد | فهرست جداگانه |
| کوادراتوری | شامل `∫ f(x) dx` و پرچم `closed_form=false` |

`C` ثابت اول، `C2` ثابت دوم و به همین ترتیب است.

---

## ۷. نمونه‌های آماده

```
y' = x/y
y' = (x^2+y^2)/(x*y)
y' = y
y' + y/x = x^2
y' = y^2
y' = 1 + y^2
y' = x*y + y^2
y' = (x+y)^2
y = x*y' + (y')^2
y = 2*x*y' + (y')^2
(2x+y) + (x+2y)*y' = 0
(x+y)dx + (x+2y)dy = 0
2*y + x*y' = 0
y'' - 3y' + 2y = 0
y'' + y = 0
y'' = 6x
y'' - y = 0
```

## ۸. محدودیت‌های پارسر

- عمق عبارت حداکثر ۲۰۰ است.
- نام تابع‌ها به حروف کوچک تبدیل می‌شوند (`SIN(x)` = `sin(x)`).
- ضرب ضمنی بین دو نام متغیر (`xy`) **پشتیبانی نمی‌شود**؛ `x*y` بنویسید.
- `log` همیشه لگاریتم طبیعی است؛ لگاریتم در پایهٔ دیگر را با `ln(x)/ln(b)` بنویسید.
- `|...|` فقط برای قدر مطلق است و در عبارت‌های تودرتو با احتیاط استفاده شود.
